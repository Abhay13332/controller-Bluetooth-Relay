# Xbox Controller -> Android Bluetooth Gamepad Bridge (Optimized)

A high-performance Windows background application that reads inputs from a wired Xbox controller connected to your PC and forwards them to your Android device by emulating a **Bluetooth Low Energy (BLE) HID Gamepad**.

---

## 🚀 Key Improvements & Optimizations

1. **Input Interceptor (Swallows Controller Typing in Windows):**
   * Automatically intercepts and swallows synthetic keystrokes injected by **Steam's "Desktop Layout"** or **Windows Game Bar** (e.g. A mapped to Enter, B mapped to Backspace/Esc, D-pad mapped to arrows). when setup with hidhide.
   * **Your physical keyboard and mouse remain 100% functional** for normal PC work.
2. **Fixed Android Input Delivery (Linux UHID Standard):**
   * Prepends the standard `0x01` Report ID header matching Android's kernel Linux UHID driver expectations.
   * Corrected Linux axis assignments (`ABS_X`/`ABS_Y` for Left Stick, `ABS_RX`/`ABS_RY` for Right Stick, `ABS_Z`/`ABS_RZ` for Triggers).
3. **Ultra-Low Latency (< 4ms / 250 Hz):**
   * Uses Windows multimedia timer (`timeBeginPeriod(1)`) to force 1ms OS timer resolution (down from standard 15.6ms).
   * Employs a non-blocking **coalescing transmitter**: controller polling runs at 250 Hz without waiting for Bluetooth ACKs, eliminating all frame-queue lag.
   * Throttled UI rendering to 4 FPS so console output never delays controller input.

## 🛠️ Quick Start

### 1. Launch the Bridge
* **Interactive Mode:** Double-click [`run.bat`](run.bat).
* **Silent Background Mode:** Double-click [`run-hidden.vbs`](run-hidden.vbs).

### 2. Connect to Android
1. **CRITICAL IF PREVIOUSLY PAIRED:** Open Android Bluetooth Settings, tap the gear icon next to your PC, and tap **"Unpair" / "Forget"**.
2. Scan and tap your PC to pair. (This forces Android to re-read the updated HID button descriptor).
3. Android will display the connected device with a **Gamepad icon**.

## 🛑 How to Prevent Controller Input from Reaching Windows OS

### Method 1: Built-in Input Interceptor (Active by Default)
The bridge automatically runs [`InputInterceptor`](InputInterceptor.cs), which detects and swallows injected keyboard events generated by background mappers like Steam.

### Method 2: Disable Steam Desktop Layout (Recommended)
If Steam is running, Steam translates your controller into a mouse/keyboard on your desktop:
1. Open Steam.
2. Go to **Settings** > **Controller**.
3. Under **Desktop Layout**, click **Edit**.
4. Click the gear icon > select **Disable Steam Input** (or choose a blank template).
5. Alternatively, right-click the Steam tray icon and select **Exit Steam** while gaming on Android.

### Method 3: 100% Total Kernel Cloaking via HidHide (Best)
If you want Windows games and all PC software to completely ignore the Xbox controller:
1. Install [HidHide](https://github.com/nefarius/HidHide/releases).
2. Double-click [`tools\setup_hidhide.bat`](tools/setup_hidhide.bat) to automatically whitelist `BluetoothGamepadBridge` and cloak the Xbox controller from the rest of Windows.
